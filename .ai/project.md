# Настройки конкретного контеста

Этот файл — редактируемый источник правил проекта. Заполните неизвестные поля
по репозиторию и официальным условиям игры. Значение «не задано» не является
командой и не разрешает агенту выдумывать её. После изменений выполните синхронизацию.

## Игра и источники

| Параметр | Значение |
| --- | --- |
| Название контеста | CodinGame Code Royale — постоянная multiplayer-арена (slug `code-royale`, puzzle id 383), не идущий контест |
| Лига / вариант правил | Лиги: Wood 3 → Wood 2 → Wood 1 → Bronze → Silver → Gold → Legend (`divisionIndex` 0..6). Полные правила открываются с Bronze (referee level 4+); Silver/Gold/Legend новых механик не добавляют. Текущая лига пользователя: не задана |
| Официальные правила: URL или путь | https://www.codingame.com/multiplayer/bot-programming/code-royale; копии: `docs/rules/` (см. `docs/rules/README.md`) |
| Referee: репозиторий, версия / commit | https://github.com/csj/code-royale @ `349924a140258107a5f6f75d5d6bde717e12ae3b` (2019-03-16), Kotlin; локальная копия `refs/referee-csj/` (gitignored, только чтение). Live-statement ссылается на `csj/team-2` → редирект на этот же репозиторий |
| Известные расхождения правил и referee | **Лимит ходов: live = 250** (live-statement Wood 3 и 24 из 88 реплеев Legend 2026-10-28 длиной ровно 250 ходов), в репозитории `maxTurns = 200` и statement «200». Прочие расхождения не проверены — проверять реплеями (`cg-validate-simulator`) |
| Число игроков, очередность / одновременность ходов | 2 игрока, одновременные ходы. Конфликт BUILD на одном сайте: в чётный ход строит игрок 2, в нечётный — игрок 1 (Bronze+ statement) |
| Победа, ничья, ранжирование игроков | Уничтожение вражеской королевы; обе за один ход — ничья; по лимиту ходов побеждает королева с большим HP (детали ничьей при равном HP — проверить по referee) |
| Скрытая информация и доступные боту наблюдения | Золото и maxMineSize сайта видны только в радиусе обзора королевы (`QUEEN_VISION = 300`) или для своих шахт, иначе -1. Остальное (юниты, постройки, HP) видно |

## Особые правила проекта

- Старый проект `C:\Disk_D\Programming\IdeaProjects\CodeRoyale\` — только справка; код из него не переносить.
- `refs/referee-csj/` — референс для порта правил и генератора карт (`java.util.Random(seed)`, seed есть в `refereeInput` реплея); при порте использовать live-константы (250 ходов), а не значения репозитория.
- Правила живут только в `core`; каждое изменение правил — тест и зелёная сверка с реплеями.
